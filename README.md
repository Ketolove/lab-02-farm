Вариант 2. Подсчёт ресурсов
В input.txt вразнобой записаны поставки ресурсов за неделю в формате Название Количество (например: Дерево 10, Камень 5, Дерево 15, Семена 4, Камень 8). Названия могут многократно повторяться. Программа должна считать данные (используя массивы строк и чисел), объединить одинаковые наименования, просуммировав их количество, и вывести в output.txt чистую сводную ведомость без дубликатов (например: Дерево: 25 шт., Камень: 13 шт., Семена: 4 шт.).
